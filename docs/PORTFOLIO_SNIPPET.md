# Portfolio Snippet

## Short Project Description

IBMatlab RL Trading System is a MATLAB research project that combines technical
signal engineering with a DQN-style reinforcement-learning execution agent. The
system builds market state features from OHLCV data, aggregates multiple trading
signals, trains a custom MATLAB RL environment, and separates safe simulated-data
experiments from broker-connected paper-trading wrappers.

## Resume Bullet
